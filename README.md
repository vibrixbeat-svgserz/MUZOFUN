# MUZOFUN REAL — Railway

Настоящая пользовательская музыкальная платформа без фейковых треков.

## Возможности
- регистрация/вход;
- загрузка настоящих аудиофайлов;
- пользовательские обложки;
- реальное воспроизведение через HTML Audio;
- реальные лайки и прослушивания;
- поиск;
- личная библиотека;
- плейлисты;
- PostgreSQL.

## Railway
1. Добавь PostgreSQL в проект.
2. Добавь Volume и укажи Mount Path `/data`.
3. Добавь переменную `JWT_SECRET` со случайным длинным значением.
4. Deploy.

`DATABASE_URL` Railway выдаёт PostgreSQL автоматически. Приложение слушает `0.0.0.0:$PORT`.

Если Volume не подключён, приложение может работать, но загруженные файлы будут храниться на эфемерном диске текущего контейнера. Для постоянного хранения музыки нужен Volume.
